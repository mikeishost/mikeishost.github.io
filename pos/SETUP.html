🚀 St. Thomas POS Setup Guide

Bluefy-Compatible Serverless iOS Point of Sale Application

⚡ Quick Start (5 Minutes)

Step 1: Deploy Files

Upload all files to an HTTPS-enabled web server:

  • index.html
  • styles.css
  • storage.js
  • receipt.js
  • bluetooth.js
  • app.js

Step 2: Open in Bluefy

On your iOS device:

  1. Install Bluefy Web Browser from App Store
  2. Grant Bluetooth permissions when prompted
  3. Navigate to your HTTPS URL

Step 3: Pair Printer

On the POS app:

  1. Tap the "Connect" button
  2. Select your BLE thermal printer from the list
  3. Device ID will be saved for fast reconnection

✨ Core Features

📱 Mobile-First UI

Touch-optimized interface designed specifically for iOS. Large buttons, smooth animations, and responsive layout.

🛒 Smart Cart

Add/remove items instantly. Long-press to edit item names and prices. Changes saved to localStorage automatically.

🔗 Web Bluetooth

Direct BLE connection to 58mm thermal printers. No intermediate servers. Completely offline-capable once loaded.

💾 Persistent Storage

All data (items, cart, paired devices) saved to browser localStorage. Survives page reloads and app reopens.

🖨️ Smart Print

Automatic chunking (100-byte chunks) prevents printer buffer overflow. ESC/POS formatted receipts with proper alignment.

⚙️ Lightweight

Vanilla JavaScript, no frameworks or build tools. Fast loading, minimal dependencies, instant startup.

📋 System Requirements

Component Requirement Notes
iOS Version 15.0 or higher Web Bluetooth API requires iOS 15+
Browser Bluefy Web Browser Safari on iOS does not support Web Bluetooth
Connection HTTPS (Secure) Web Bluetooth requires secure context
Printer BLE Thermal (58mm) Generic Chinese printers compatible
⚠️ Important: HTTPS is mandatory for Web Bluetooth API. Your domain must have a valid SSL certificate.

🎨 Customization Guide

Change Store Name on Receipt

Edit receipt.js, find line ~92 and modify the header text:

// Change this line: receiptBytes.push(stringToBytes('St. Thomas @ Surprisesss')); // To your store name: receiptBytes.push(stringToBytes('Your Store Name Here'));

Adjust Print Speed

If receipt cuts off, increase delay in bluetooth.js:

const DELAY_MS = 75; // Change to 100-150 for slower printers // Chunk size can also be adjusted: const CHUNK_SIZE = 100; // Decrease to 50-75 for tiny buffers

Modify Default Items

Edit storage.js, line ~14:

const DEFAULT_ITEMS = [ { id: 1, name: 'Chicken Rice', price: 5.50 }, { id: 2, name: 'Pork Noodles', price: 6.00 }, // Add your items here ];

Change UI Colors

Edit styles.css, line ~8 (CSS variables):

:root { --primary-color: #1a73e8; /* Google Blue */ --secondary-color: #34a853; /* Google Green */ --danger-color: #d33427; /* Google Red */ /* ... more colors ... */ }

🔧 Troubleshooting

❌ "Web Bluetooth not available"

This means your browser doesn't support Web Bluetooth. Solution:

  • ✅ Use Bluefy Web Browser on iOS
  • ⚠️ Standard Safari on iOS does NOT support Web Bluetooth
  • ℹ️ On Android, use Chrome/Edge with Web Bluetooth enabled

❌ Printer not found during scan

If your printer doesn't appear in the device list:

  • ✅ Ensure printer is powered on
  • ✅ Check printer is in pairing/discovery mode
  • ✅ Move iOS device closer to printer
  • ✅ Restart Bluefy and try again
  • ✅ Restart printer if still not found

❌ Print cuts off or incomplete

Printer buffer overflow is occurring. Try:

  • ✅ Increase DELAY_MS in bluetooth.js (75 → 100-150ms)
  • ✅ Decrease CHUNK_SIZE in bluetooth.js (100 → 50-75 bytes)
  • ✅ Check printer specifications for buffer size

❌ Receipt format looks wrong

Printer may not support standard ESC/POS. Check:

  • ✅ Printer manual for ESC/POS command support
  • ✅ Try different text encodings (UTF-8 is default)
  • ✅ Test simple print commands via other apps

❌ Cannot reconnect to paired printer

Auto-reconnection may not work in some cases:

  • ✅ Tap "Connect" again to rescan and pair
  • ✅ Printer may have reset - re-pair if needed
  • ✅ Clear browser data to reset pairing (localStorage > pos_pairedPrinterId)

⚡ Performance Optimization Tips

✅ Why This App is Fast:
  • Zero build process - runs directly in browser
  • No external dependencies or frameworks
  • localStorage persists data instantly
  • Direct BLE connection - no server latency
  • Minimal CSS animations only when needed
ℹ️ Further Optimization Options:
  • Cache entire app using Service Worker for offline mode
  • Enable HTTP/2 Server Push for faster asset delivery
  • Minify CSS/JS for smaller file sizes
  • Use WebP images if adding store logos

🖨️ ESC/POS Command Reference

Command Hex Code Purpose
INIT 1B 40 Initialize printer to default state
CENTER 1B 61 01 Set center text alignment
LEFT 1B 61 00 Set left text alignment
BOLD ON 1B 45 01 Enable bold text font
BOLD OFF 1B 45 00 Disable bold text font
LINEFEED 0A Move to next line
CUT PAPER 1D 56 42 00 Cut paper at current position
ℹ️ Note: If printer doesn't support certain commands, it will simply ignore them. The app gracefully handles unsupported features.
